# Renderizeitor

OpenGL based renderer for the TeREp2 project

**Vibe coded using Claude**, it compiles as a optional DLL plugin, kept in a separate repo so LLM and flesy code dont mix, if you dont want to use LLM generated things just dont use this plugin 👍

## Improvements

 * Higher resolution (haven't tested high-res textures yet, they should work for cars, for the ground its easy to implement)
 * Realtime shadows
 * World border visuals
